# PostMedia

Public media for WorkstyleIQ posts.

## linkedinposts/heroes/

Hero images for WorkstyleIQ Thought Leader LinkedIn posts, one folder per post: `linkedinposts/heroes/<slug>/`.

Images are copied here automatically by the LinkedIn post review sync (WorkstyleIQ/LinkedInPosts) when a post is accepted on the Post Review Desk. The public URL is then attached to the post's Buffer draft.

Do not edit or remove images for posts that are scheduled or live, since Buffer and LinkedIn link to them.
